# Suraj Kumar Portfolio

A responsive static portfolio based on the supplied portfolio reference image and resume.

## Run locally
Open `index.html` in a browser.

For a local server:
- VS Code Live Server, or
- `python -m http.server 8000`

## Important
The portfolio uses claims supported by the supplied resume. Replace `assets/Suraj_Resume.pdf` with your final PDF resume if you want the Download Resume button to point to PDF; the supplied DOCX is included as `assets/Suraj_Resume.docx`.

The portrait in `assets/suraj-photo.jpg` is cropped from the supplied portfolio reference image.
